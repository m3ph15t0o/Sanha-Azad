### 🔬 Featured Project: Digital Evidence Integrity Checker

> **Problem Solved:** In digital forensics, proving that evidence has not been altered after collection is critical. This tool calculates and verifies cryptographic hashes to detect even a single-byte modification.

<div align="center">

| 📥 Step 1: Evidence Input | ⚙️ Step 2: Cryptographic Engine | ✅ Step 3: Integrity Verdict |
| :---: | :---: | :---: |
| Raw Digital File / Disk Artifact | Computes SHA-256 & MD5 Fingerprints | Compares Hashes & Flags Tampering |

</div>

- **Key Features:** Automated file scanning, cryptographic hash generation (`hashlib`), and tamper-detection reporting.
- **Built With:** Python, Linux File Systems, Cryptographic Hashing Algorithms.
